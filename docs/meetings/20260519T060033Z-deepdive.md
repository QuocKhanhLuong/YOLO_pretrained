Date: 2026-05-19 06:00 UTC

## Health: NO ACTIVE RUN

## External Signals (Researcher)

- YOLO tooling expects split-aligned `images/{train,val,test}` and `labels/{train,val,test}` folders with matching relative basenames.
- YOLO label validation should be strict: exactly five values per row, normalized coordinates, positive width/height, and class IDs within the class map.
- `data.yaml` is the training contract, so generated paths must be stable and not depend on the current working directory.
- Reproducible splitting needs a fixed seed and deterministic image-label pair handling.
- DVC should version prepared data artifacts through `.dvc` pointer files; scripts should not run DVC automatically.
- Documentation should avoid implying that a real dataset is included locally.

## Internal Health (Architect)

- The repo started as an AgenTeam scaffold with no scripts, docs, tests, or dataset files.
- The requested implementation should remain standard-library only and CLI-first because the real dataset is server-side.
- Main edge cases are empty label files, missing labels, orphan labels, invalid class IDs, non-normalized boxes, duplicate image stems, unsupported extensions, and overwrite protection.
- The local directory is not currently a Git repository, so Git/DVC commands are documented but not run here.
