## Dataset Findings

- Filtering/remap looks sane: `vehicle` is class `0`, `soldier` is class `1`.
- `fire` was removed from `data_v1.1_vehicle_soldier`.
- Split counts remain `train=888`, `val=111`, `test=112`.
- Empty labels increased by design because images with only removed classes were kept as background negatives:
  - train: 283
  - val: 41
  - test: 29
- Class imbalance remains:
  - train: `vehicle=318`, `soldier=700`
  - val: `vehicle=37`, `soldier=81`
  - test: `vehicle=37`, `soldier=103`
- Boxes are often small. Median bbox area is about `0.0097`, and vehicle median area is lower than soldier.

## Training Findings

- Train losses decrease steadily through the run.
- Validation losses bottom out much earlier:
  - `val/box_loss` best at epoch 24
  - `val/cls_loss` best at epoch 14
  - `val/dfl_loss` best at epoch 13
- Best mAP occurs later, around epochs 42-47, then final metrics decline.
- This is not solved by more epochs; the primary issues are generalization, class imbalance, small objects, and validation noise.

## Suggested Next Experiments

### A. Vehicle-Focused Baseline

- Keep `imgsz=1280`.
- Use `lr0=0.0002`.
- Use `patience=30`.
- Keep `batch=16` if GPU is stable.
- Track per-class AP and recall, not just all-class mAP.

### B. Drop-Empty Variant

Create a separate dataset version:

```bash
python scripts/filter_yolo_classes.py \
  --source-dataset data/versions/data_v1.0 \
  --output data/versions/data_v1.1_vehicle_soldier_drop_empty \
  --version data_v1.1_vehicle_soldier_drop_empty \
  --include-classes vehicle soldier \
  --drop-empty-after-filter
```

This checks whether the 353 empty-label negatives help or suppress recall.

### C. Add/Oversample Vehicle Data

Vehicle has far fewer instances than soldier. Before major model changes, add or
oversample vehicle examples and inspect missed vehicle frames manually.

### D. Small Object Strategy

If `imgsz=1280` is still missing small objects, the next dataset phase should be
tiling/cropping rather than only increasing epochs.
