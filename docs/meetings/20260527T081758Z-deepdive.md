## External Signals (Researcher)

- Ultralytics training runs commonly expose `results.csv`, `args.yaml`,
  `weights/best.pt`, `weights/last.pt`, `results.png`, confusion matrices,
  PR/P/R/F1 curves, and validation batch images; the report should discover
  available files rather than require all of them.
- Aggregate detection metrics should be read together: `mAP50-95`, `mAP50`,
  precision, recall, and train/validation losses tell different parts of the
  model-quality story.
- Qualitative prediction review is necessary for UAV small-object work because
  aggregate mAP can hide missed tiny objects, duplicate boxes, class swaps, and
  background false positives.
- Class imbalance can hide rare-class failure, so the report should count YOLO
  label instances per class and flag minority classes.
