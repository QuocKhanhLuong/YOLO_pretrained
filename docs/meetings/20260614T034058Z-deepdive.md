## External Signals (Researcher)

- `docs/research/` is absent, so there are no prior local research notes to mark stale.
- Ultralytics now documents YOLO26 as a current model family with `yolo26n.pt` through `yolo26x.pt`, native end-to-end inference, a lighter detection head, and updated training recipe details. Source: https://docs.ultralytics.com/models/yolo26/
- YOLO11 remains a stable baseline with `yolo11n.pt`, `yolo11s.pt`, `yolo11m.pt`, `yolo11l.pt`, and `yolo11x.pt` detection weights supported for training, validation, inference, and export. Source: https://docs.ultralytics.com/models/yolo11/
- Ultralytics detection datasets use a root `path` plus relative `images/train`, `images/val`, and optional `images/test` paths, matching this repo's prepared dataset convention. Source: https://docs.ultralytics.com/datasets/detect/
- Experiment tracking expectations are moving toward repeatable metrics, artifact logging, model comparison, resource usage, and prediction overlays; W&B is one documented path, but local Markdown/CSV artifacts remain important for portable runs. Source: https://docs.ultralytics.com/integrations/weights-biases/

## Internal Health (Architect)

- High: `scripts/create_dataset_variant.py` and `scripts/run_batch_training.py` were missing before this task, so the repo had no reusable Python workflow for RGB/Thermal dataset variants or dry-runnable multi-model batches.
- High: `scripts/run_waruav_v3_suite.sh` is useful but brittle for long GPU jobs because it is shell-only, exits on first failure, and does not maintain a structured per-model status ledger.
- High: dataset validation logic is duplicated across several scripts. The new variant creator should remain focused, and a later cleanup can extract shared YOLO label helpers.
- Medium: existing docs were still centered on `data_v1.0` and `data_v2.0`; the requested boss-style setup needs `data_v3.1` commands and output expectations in `docs/TRAINING_GUIDE.md`.
- Medium: `train_yolo.py` metadata can remain `started` when training fails. The new batch summary mitigates this at orchestration level, but failed-run metadata should be hardened later.
- Low: multimodal fusion should stay out of the first release until RGB-only and thermal-only baselines expose a clear need and paired-modality integrity is proven.
